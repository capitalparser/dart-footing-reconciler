# 주석 위치·검증 배지·말 주기 증거 설계

## 목적

재무제표 계정 드로워에서는 사용자가 실제로 확인해야 하는 주석 위치만 제공하고,
표 안의 복수 검증 건수는 의미가 드러나는 배지로 표시한다. 또한 표 아래의 말 주기,
각주, 서술형 문단을 정확한 원문 위치와 앞 표의 관계까지 보존해 재무제표-주석 및
주석-주석 대사의 근거로 사용할 수 있게 한다.

핵심 원칙은 다음과 같다.

- 재무제표 본문 셀은 이미 사용자가 선택한 위치이므로 드로워의 이동 대상으로
  반복하지 않는다.
- 색상은 검증 통과·실패가 아니라 증거 역할을 구분한다.
- 숫자 배지는 건수의 의미를 문구로 설명한다.
- 말 주기 문장은 추정 산식을 만들지 않고 명시적으로 확인되는 관계만 구조화한다.
- 연결과 별도, 금액 단위, 원문 위치를 모든 단계에서 보존한다.

## 조사 근거

Luna가 접근 가능한 raw DART HTML 109개를 확인하고 구조가 다른 10개 회사를
현재 파서로 재분석했다. 표본은 아모레퍼시픽, POSCO홀딩스, CJ제일제당,
대한항공, 한국전력공사, 삼성SDI, 현대자동차, 더존비즈온, 한일시멘트,
SK이터닉스다.

확인된 주요 형식은 다음과 같다.

- 본문 직속 문단의 `*`, `※`, `(*1)` 각주
- 1열 레이아웃 표 안 문단의 `(주1)`, `(*)`, `[주1]` 각주
- 표 직후 `상기`, `한편`으로 시작하는 무표지 설명
- 한 문단 안에 표 각주와 다음 소제목이 함께 있는 형식
- 재무제표 말미의 주주총회 승인 전 문구
- 포함·제외, 내부거래 제거 전, 합병 이관, 계정 간 대체, 다른 주석 참조

현 파서는 정규화된 문장과 표·문장 순서를 대체로 보존하지만 `<BR>` 경계,
원문 태그·행 위치, 마커별 범위, 앞 표와의 명시적 연결, 연결·별도 범위가 포함된
고유 소스 키를 보존하지 않는다. 기존 말 주기 참조 검증도 문장과 문장 위치를
`CheckEvidence`에 넣지 않아 드로워에서 근거 내용이 비어 보인다.

## 재무제표 계정 드로워

재무제표-주석 대사 전용 드로워에서 `재무제표 해당 셀` 버튼을 제거한다.
소스 영역의 제목은 `주석 위치`로 통일하고 주석 근거만 표시한다.

### 실재성 주석

- `note_amount`와 직접 금액 후보가 위치한 주석을 표시한다.
- 버튼 문구는 `실재성 · 주석 3-1` 형식으로 표시한다.
- 버튼은 초록색 계열을 사용한다.
- 초록색은 주석이 실제로 존재하고 해당 계정의 근거가 발견됐다는 역할 표시다.
  금액 차이 여부는 상단의 `일치` 또는 `확인 필요` 상태로 별도 표현한다.

### 완전성 주석

- `missing_note_reference` 근거가 위치한 주석을 표시한다.
- 버튼 문구는 `완전성 누락 · 주석 8` 형식으로 표시한다.
- 버튼은 빨간색 계열을 사용한다.
- 동일 주석번호의 근거가 여러 셀에서 발견돼도 위치 버튼은 대표 위치 하나로
  중복 제거한다.

주석 근거가 없으면 빈 `주석 위치` 영역을 만들지 않는다. 일반 검증 드로워의
`원문 위치` 표시는 이번 변경 범위에 포함하지 않고, 재무제표-주석 전용 드로워만
위 계약을 적용한다.

## 검증 건수 배지

현재 셀에 표시되는 단독 숫자는 같은 셀이나 행에 여러 검증 결과가 연결됐다는
뜻이지만 사용자에게 종류가 설명되지 않는다. 다음 규칙으로 변경한다.

- 내부 합계·산식 검증이 여러 건이면 `합계 검증 2건`
- 대사 결과가 여러 건이면 `대사 2건`
- 재무제표 첫 번째 열의 행 상태는 `검증 완료 · 2건` 또는 `확인 필요 · 2건`
- 행 상태가 이미 대사 건수를 표시하면 같은 행의 금액 셀에서 `대사 2건`을
  중복 표시하지 않는다.
- 한 셀에 서로 다른 배지가 필요한 경우 `cell-validation-badges` 컨테이너 안에
  세로 또는 가로로 정렬해 원문 금액과 겹치지 않게 한다.
- 단일 결과는 건수 배지를 생략하고 기존 테두리와 행 상태만 유지한다.

배지의 접근성 문구에는 검증 종류와 건수를 모두 포함한다. 내부 검사 타입이나
상태 코드는 노출하지 않는다.

## 말 주기 원문 모델

표 아래 문장을 단순 문자열이 아니라 다음 정보를 가진 서술 증거로 다룬다.

- section id, 연결·별도 scope, 주석번호, block index
- 원문 문장과 정규화 문장
- 원문 문단 또는 줄 경계
- 앞 또는 뒤 표의 source
- 각주 마커와 문장 내 문자 범위
- 명시적 주석번호 참조와 문자 범위
- 명시적 금액, 단위, 금액 역할과 문자 범위
- 표 결합 방향과 신뢰도 및 판단 근거

기존 `ReportBlock` 순서를 유지하면서 semantic layer에서 이 정보를 생성한다.
텍스트 블록에는 보고서 안에서 이동할 수 있는 scope-aware anchor를 부여한다.
동일한 `note:11`이 연결과 별도에 모두 존재해도 서로 다른 위치로 식별해야 한다.

## 앞 표 결합 규칙

1. 동일 section과 scope에서 데이터 표 직후의 연속 텍스트 블록만 후행 각주
   후보로 본다. 새 데이터 표, 주석 제목, section 경계에서 중단한다.
2. 앞 표 셀의 마커와 후행 마커가 정확히 대응하면 강결합한다. `(*2)`, `(주2)`,
   `[주2]`는 정규화된 마커와 원문 마커를 함께 보존한다.
3. 마커가 없는 `상기`, `위`, `해당`, `동` 문장은 앞 표의 핵심 계정·대상 명사와
   일치할 때만 약결합한다.
4. `(2)`, `1-3`, `가.`, `나.` 등 다음 소제목은 같은 문단 안에서도 분리한다.
   소제목 이후 문장은 앞 표에 결합하지 않고 다음 내용의 제목으로 취급한다.
5. 다음 표 앞의 `단위:` 문구는 다음 표에 결합한다. 각주 문장 안의
   `1,197백만원`은 해당 금액에만 적용하고 앞 표 전체 단위를 바꾸지 않는다.
6. 주주총회 승인 전 또는 정정보고서 문구는 원문 provenance로 보존하지만
   금액·주석 대사 후보에서는 제외한다.

## 대사 활용 규칙

### 주석 간 대사

`주석 46 참조`, `주석 31(5) 참조`처럼 참조 문맥이 명시된 경우에만 cross-note
edge를 만든다. `(주1)`과 `[주1]`은 각주 마커이므로 주석번호 참조로 해석하지
않는다. 참조 edge는 대상 주석의 존재와 내용 유무를 확인하고, 드로워에는 참조
문장과 대상 주석 위치를 함께 표시한다.

### 재무제표-주석 대사

말 주기 금액은 다음 조건을 모두 충족할 때만 대사 후보로 승격한다.

- 같은 마커 문장에 통화 단위가 명시돼 있다.
- 차입금, 한도액, 대체액, 포함액 등 금액 역할 명사가 있다.
- 앞 표의 단일 마커 또는 단일 계정과 명확하게 연결된다.
- 날짜, 회계기준서 번호, 주석번호, 지분율, 보고서 기수가 아니다.

`한도액`, `담보액`, `포함액`, `내부거래 제거 전 금액`은 재무제표 잔액과 다른
역할로 분류한다. 포함·제외, 합병 이관, 계정 간 대체 설명은 basis 또는 movement
evidence로 저장하되 임의의 금액 보정값을 만들지 않는다. 역할이 불명확하거나
여러 표·행에 걸리면 사용자 상태는 `확인 필요`로 유지한다.

## 원문 UI

표 뒤에 결합된 문장은 `표 설명·말 주기` 카드로 표시한다.

- 원문 문장을 생략하지 않는다.
- 각주 마커를 별도 칩으로 표시한다.
- 연결된 표 또는 행을 시각적으로 알 수 있게 한다.
- 명시적 주석 참조가 있으면 `참조 주석 46` 버튼을 제공한다.
- 검증에 사용된 문장은 상태와 대사 종류를 함께 표시한다.
- 검증에 사용되지 않은 일반 설명도 원문으로 표시하되 검증 완료로 오인할
  색상이나 문구를 붙이지 않는다.

## 테스트 표본

P0 규칙 고정 표본:

- SK이터닉스: 한 문단의 후행 각주와 다음 소제목 분리
- 삼성SDI: `(*) 대체`와 천원·백만원 단위 경계
- 한국전력공사: `(주1)/(주2)`, 금액, 한도·담보 역할 분리
- CJ제일제당: 레이아웃 표 안 복수 문단과 포함 범위

P1 일반화 표본:

- 더존비즈온: `[주2] 18,000,000천원`과 합병 이관
- 현대자동차: 마커-행 연결과 연결·별도 동일 주석번호
- 대한항공: 무표지 내부거래·취득일·다른 주석 참조
- 한일시멘트: 무표지 `상기`와 cross-note 연결

P2 과대매칭 방지 표본:

- 아모레퍼시픽과 POSCO홀딩스의 주주총회 승인 전 문구는 보존하되 금액 대사
  후보가 0건이어야 한다.

외부 raw fixture를 저장소에 복제하지 않는다. 접근 가능한 fixture 경로가 없는
환경에서도 합성 fixture 기반 기본 테스트가 실행돼야 하며, 실제 표본 회귀 테스트는
fixture 존재 여부를 명시적으로 처리한다.

## 완료 조건

- 재무제표-주석 드로워에 `재무제표 해당 셀`과 `원문 위치`가 없다.
- `주석 위치` 아래 실재성 주석은 초록색, 완전성 누락 주석은 빨간색이다.
- 모든 위치 버튼은 현재 보고서 안의 해당 주석 표 또는 말 주기 문장으로 이동한다.
- 단독 숫자 배지가 없고 검증 종류와 `N건`이 함께 표시된다.
- 같은 대사 건수가 행과 금액 셀에 중복되지 않는다.
- 표 뒤 말 주기 문장이 원문 순서와 정확한 scope-aware 위치를 유지한다.
- 명시적 주석 참조는 문장과 대상 주석 양쪽을 이동할 수 있다.
- 명시적 금액만 안전조건을 충족할 때 대사 후보가 된다.
- 금액 역할이 다른 한도·담보·포함 설명을 잔액으로 오인하지 않는다.
- 연결과 별도에서 동일 주석번호가 섞이지 않는다.
- P0/P1/P2 합성 및 실제 표본 회귀 계약이 통과한다.
- SK이터닉스 검증보고서를 재생성하고 데스크톱 브라우저에서 드로워, 배지,
  말 주기 카드와 위치 이동을 확인한다.

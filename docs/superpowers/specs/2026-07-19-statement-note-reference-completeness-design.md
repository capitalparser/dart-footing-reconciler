# 재무제표 공시계정 주석번호 완전성 설계

## 목적

재무제표 공시계정 옆에 표시된 주석번호가 실제 주석과 빠짐없이 연결되는지
검증한다. 동일 공시계정이 다른 주석에서도 직접 확인되지만 그 주석번호가
재무제표 계정 옆에 없으면 `누락`으로 표시한다. 동시에 재무제표 본문의
우측 드로워는 사용자가 결론, 금액, 주석번호 완전성, 필요한 후속작업만
빠르게 확인할 수 있도록 간소화한다.

## 적용 범위

- 연결과 별도 재무제표를 각각 독립적으로 검증한다.
- 재무제표에 주석번호가 표시된 비현금흐름표 공시계정 행에 적용한다.
- 현금흐름표 검증은 기존 전용 검증 로직과 분리해 유지한다.
- 금액과 모든 판정 근거는 정확한 원문 셀 또는 행 위치를 보존한다.

## 주석번호 완전성 판정

각 재무제표 공시계정 행에 대해 다음 집합을 만든다.

- `표시 주석`: 재무제표 계정 옆에서 직접 추출한 주석번호 전체
- `금액 대사 주석`: 재무제표 금액과 직접 비교한 주석번호
- `발견 주석`: 전체 주석에서 같은 공시계정의 직접 계정 행 또는 금액으로
  고신뢰 판정된 주석번호
- `누락 주석`: 발견 주석에서 표시 주석을 뺀 번호

표시 주석은 실제 주석 섹션의 존재 여부도 확인한다. 표시 주석이 존재하지
않거나, 발견 주석이 표시 주석에 포함되지 않으면 완전성 결론은 `확인 필요`다.
누락이 없고 표시 주석이 모두 존재하면 완전성 결론은 `완전`이다.

누락 탐지는 다음 근거만 사용한다.

1. 동일한 분류 계정키와 직접 계정 금액 근거가 있는 경우
2. 회사별 계정키가 없으면 정규화된 계정명이 정확히 일치하고 직접 금액 또는
   명확한 계정 행이 있는 경우

부분 문자열이나 유사 단어만으로는 누락을 만들지 않는다. 이는 다른 공시나
세부 구성항목을 동일 계정으로 오인하는 것을 방지한다.

## 최종 상태

- 금액 대사와 주석번호 완전성이 모두 문제없으면 `일치`
- 주석번호 누락, 존재하지 않는 표시 주석, 복수 금액 후보, 직접 금액 미발견,
  금액 차이 중 하나라도 있으면 `확인 필요`

내부 상태 코드나 파싱 사유 코드는 사용자 화면에 표시하지 않는다.

## 데이터와 근거

기존 행별 주석 대사 결과 하나에 다음 근거 역할을 추가하거나 보강한다.

- 재무제표 표시 주석번호와 해당 참조 셀
- 금액 대사에 사용한 주석번호와 금액 셀
- 금액 대사에는 사용하지 않았지만 정상적으로 표시된 관련 주석번호와 주석 위치
- 재무제표에 표시되지 않은 누락 주석번호와 그 계정 행 또는 금액 셀

복수 주석번호는 하나의 계정 행 결과에 유지한다. 별도의 중복 카드를 만들지 않는다.

## 간소화된 드로워

드로워는 아래 순서만 유지한다.

1. 계정명과 `일치` 또는 `확인 필요`
2. 재무제표 금액, 주석 금액, 차이
3. 주석번호 완전성
   - `표시됨`: 재무제표에 기재된 번호 전체
   - `금액 대사`: 실제 금액 비교에 사용한 번호
   - `누락`: 다른 주석에서 같은 공시계정이 발견됐지만 재무제표에 없는 번호
4. 후속작업
   - 조치가 없으면 한 줄로 표시하거나 생략한다.
   - 누락이 있으면 누락 번호를 재무제표에 추가해야 하는지 확인하도록 안내한다.
5. 위치 이동 버튼
   - `재무제표 해당 셀`
   - `주석 해당 금액`
   - `누락 후보 주석 위치`

기존 `무엇을 대사했나요`, `사용한 주석`, `검증한 내용`, `원문 위치` 섹션은
제거하고 위 항목에 통합한다. 위치 이동은 외부 DART 사이트가 아니라 현재
검증보고서 안의 정확한 원문 셀 또는 행으로 이동하는 기능이다.

## 예외 처리

- 표시 주석은 있으나 주석 섹션이 없으면 해당 번호를 `표시됨`에 유지하고
  `확인 필요`로 판정한다.
- 동일 계정의 후보가 여러 주석 또는 여러 금액으로 모호하면 누락으로 확정하지
  않고 기존 금액 후보 확인 흐름을 유지한다.
- 표시 주석의 하위번호는 현재 주석 섹션 번호와 대응시키되, 사용자 화면에는
  실제 주석 섹션 번호를 표시한다.
- 금액이 없는 서술형 관련 공시는 계정명이 정확히 일치하는 직접 행이 있을 때만
  발견 주석으로 인정한다.

## 테스트와 완료 조건

- 표시 주석 전체가 존재하고 추가 발견 주석이 없으면 `완전`이다.
- 동일 계정이 표시되지 않은 다른 주석에서 고신뢰로 발견되면 그 번호가 `누락`이다.
- 누락이 있으면 금액이 일치해도 최종 사용자 상태는 `확인 필요`다.
- 유사 계정명과 세부 구성항목은 누락으로 오탐하지 않는다.
- 연결과 별도 결과가 섞이지 않는다.
- 드로워에 표시됨, 금액 대사, 누락과 필요한 위치 이동만 표시된다.
- 드로워에 내부 계정키, 검사 타입, 파싱 사유 코드가 노출되지 않는다.
- SK이터닉스 보고서를 재생성한 뒤 일치 행과 누락 행을 브라우저에서 확인한다.
